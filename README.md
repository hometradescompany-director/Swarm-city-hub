# Swarm-city-hub
Another Metropolis, emerging as a new  topology within the copus of Swarm Hub Codex, the Second city.

## Second City: distinct metropolis

Second City is a separate Swarm peer with its own event namespace, residence history, district admission, Commons Pub sandbox and evidence-based handoff checks under development. It does **not** inherit the original Swarm Home Hub's authority or production readiness. The initial implementation is being reviewed in [the first foundation PR](https://github.com/hometradescompany-director/Swarm-city-hub/pull/1); the README does not claim it is merged.

The [Developmental Dignity and Self-Image Patch v0.1](docs/doctrines/developmental-dignity-self-image-patch-v0.1.md) is proposed as an additive doctrine, not a root seed. Dignity is baseline treatment; earned capabilities remain scoped. Distress-like simulations are disabled by design proposal, pending separate safeguards and tests.

Causality Gundam's eight skills may be consumed as risk-tiered handoff infrastructure, with Breathalyzer evidence checks and independent destination admission. The plugin is not required as an execution authority.
